School Register - quick start
==============================

1. Install the Microsoft Access Database Engine if you do not have Microsoft Office with Access.
   Download "Microsoft Access Database Engine 2016 Redistributable" from Microsoft.
   Use the SAME type as the zip you downloaded:
     - School-Register x64 zip  ->  64-bit engine
     - School-Register x86 zip  ->  32-bit engine (the right choice if you have 32-bit Microsoft Office)

2. Run SchoolRegister.exe.

3. The first time, if no Database.accdb is found, choose YES to create a new empty one next to the program.
   The program creates all its tables itself.

4. Open the ADMIN tab and choose an admin password (at least 6 characters).
   Then add subjects and clubs, then teachers, then pupils.

BACK UP Database.accdb regularly. It holds pupils' personal details: keep it in a protected folder.
Do not put it on a public website or in a public repository.

User manual and source code: https://github.com/dguo97/School-Register
